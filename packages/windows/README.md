# Play Mars Outpost on Windows

[Download the Windows ZIP](https://github.com/kroix-ovo/mars-outpost/raw/refs/heads/main/packages/windows/MarsOutpost-Windows.zip), extract it, then double-click `MarsOutpost.exe` inside the `MarsOutpost` folder. No Godot installation is needed.

Windows x86-64. The executable is unsigned. The ZIP includes launch instructions, science notes, credits and an executable checksum. Live-mission Save/Load remains unavailable in this submission prototype.

The executable was exported with Godot 4.7.2 and the approved astronaut artwork. The exported binary passed a headless title-screen startup check; ZIP integrity and its contained executable hash were verified. This packaging check does not replace the earlier gameplay regression tests.
